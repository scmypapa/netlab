# 工作台交互设计

环境、模板与工作台使用页面自然滚动。拓扑、资产、流量、性能共用顶部视图切换，保持统计与任务入口的位置稳定。

## 浏览和定位

- 资产视图集中浏览、筛选资产和网段，不再在拓扑左侧重复放一份目录。
- 拓扑的“定位对象”提供名称、IP、网段搜索和最近定位；方向键选择、Enter 定位、Esc 关闭，Ctrl+K 打开。
- 手动点击节点只选中对象并显示属性，不移动画布。只有明确使用定位入口才平滑移到目标；关掉属性栏也不重新居中。
- 属性栏首次出现轻移 8px 并淡入，进入 180ms、退出 160ms；工作区宽度在 100ms 内过渡。栏内换对象直接更新，不反复入场。

## 观察和连接

- 流量默认展示所有机器；点击图例只看一台，再点恢复全部。
- 点击通信图中的机器或连线，旁边直接显示相关报文。报文卡片可以关闭；点击单条报文打开协议层和原始字节详情。
- 性能图只显示当前悬停图表的提示，不同时弹出其他图表提示。
- 控制台、SSH、串口、RDP 在独立标签页打开，沿用原有会话权限与连接设置。

## 简洁实现

视图滑块、搜索浮层、菜单与折叠继续使用 Mantine。属性栏复用一个 `AnimatedPanel`，由 Motion 管理退出后卸载；普通内容切换共用一份淡入样式。业务只保存当前选择，不维护另一份“退出中的对象”，也没有手写关闭计时器。系统选择减少动态效果时，动画立即完成。

本次迁移仅涉及前端，Netlab 自己的路由和 API 客户端继续使用。共享授权、固化模板、草稿编辑、恢复点、服务入口与 VPN 等原生能力保留；不引入上层平台的代理、账号体系或比赛逻辑。

## 验证与发布

类型检查与生产构建：`cd web && pnpm build`。

本轮定向浏览器测试：

```sh
pnpm exec playwright test e2e/workbench.spec.ts e2e/access.spec.ts e2e/traffic.spec.ts e2e/performance.spec.ts --grep '设计迁移|environment sharing' --workers=2
```

覆盖定位、属性栏、共享授权、控制台权限、流量详情、性能下钻与悬停，以及 390 / 1366 / 1920 / 2560 宽度和日夜主题。测试数据只存在于测试中。其他既有浏览器测试中旧侧栏和底部控制台的操作步骤尚待同步；本轮未声称全量测试通过。

前端单独发布时，从当前版本复制独立发布目录，只替换其中 `web`，校验程序与配置不变后原子切换 `current`。发布前备份数据库和旧前端，保留旧目录及回退脚本。控制面与节点无需重启，也不执行数据库迁移。通过服务进程、场景配置及运行状态的前后对比，以及 Netlab 和接入平台的真实页面验证。完整程序版本更新仍使用原系统更新流程；更新正式版本会带入该版本的前端。
