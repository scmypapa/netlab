# 共享镜像与存储收敛

目标：减少重复镜像占用、创建整盘写入和跨节点磁盘传输。沿用现有 StoragePool、调度器、操作队列、vmDisk 与镜像版本。

## 执行路径

- 单机使用本地基础镜像与 qcow2 写入层。
- 多节点 VM 自动优先使用可承载该资产的共享池；显式存储选择、现有运行盘和重建保卷保持原位置。
- 每个共享池、模板版本只导入一次 RBD 基础盘，发布只读快照；实例通过原生克隆创建独立写入盘。
- 共享实例的其他节点只获取固件状态、介质和模板元数据，不下载系统盘。
- 原生恢复保留快照克隆关系，解除快照时处理真正使用的引用，避免创建时或恢复时默认整盘展平。
- 模板删除、实例删除、恢复点删除和共享池移除同步清理关联磁盘；执行错误原样进入已有任务状态。
- Ceph 初始化使用官方部署工具及安装时明确指定的存储设备；平台管理接入、池、节点和凭据。默认单副本，保留官方复制/灾备及已有备份的可选集成，默认不启用。
- OCI 继续使用现有镜像分发与节点解包缓存，不改为 RBD 镜像执行。

## 验证

在既有隔离 Ceph 上验证首次导入、并发克隆、跨节点读取、实例写入隔离、扩容、重建、原生快照恢复、模板及池清理；记录首次和缓存创建耗时以及实际 RBD 占用。保持原四资产停机。结束后停止本次验证服务。

## 当前状态

共享基础镜像、原生克隆、恢复与清理路径，以及安装器选盘和托管 Ceph 接入已完成。发布版本为 v1.0.1。
