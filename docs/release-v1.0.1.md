# Netlab v1.0.1

## 共享镜像与自动存储

- 单机沿用本地基础镜像与 qcow2 写入层；多节点 VM 自动优先使用可用共享池，显式选择与已有运行盘保持原位置。
- 每个共享池、模板版本只导入一次基础盘。实例使用 RBD 原生克隆，各自写入，创建及恢复不默认复制或展平整盘。
- 共享实例在其他节点只分发模板配置、固件状态和挂载介质，系统盘直接使用共享存储。
- 安装器默认本地数据目录，推荐最大的独立空盘，安装时接受推荐或指定专用盘。登记第二个 VM 节点后，现有任务队列自动配置 Ceph；无专用盘的计算节点也能使用共享池。
- 默认单副本，官方复制配置和 Restic 备份集成保留；扩容保持已有复制配置。
- 沿用现有调度、存储池与操作任务，修正共享盘被节点本地盘容量限制的问题。

## 修复

- 本地带基础盘引用的恢复点恢复到 RBD 时，统一系统盘和 ISO 的模板目录。
- 模板删除覆盖全部版本的共享基础盘、容器镜像与节点缓存；使用中的基础盘保留引用保护。
- 删除恢复点时处理真实克隆引用；删除共享池时清理模板基础盘，托管集群通过官方工具移除。
- Ceph 服务镜像与本机客户端使用相同版本；新增存储节点等待本机 OSD 实际运行后才完成配置。
- SSH 密码连接保存自动读取主机身份；Linux VM 启动时按稳定网卡身份适配静态 Netplan 配置。
