# 实施记录

基准：`design/design.md`、`design/product-comparison.md`。平台代码参考为 `bff10f0`，新产品独立开发。

## 施工顺序

1. 基础执行闭环：契约、PostgreSQL 任务、容量预留、模板、虚拟硬件、启动前容器网络、混合环境创建与销毁。
2. 网络与运行变更：跨节点、重叠网段、多网卡、差异预览与应用、服务入口、VPN、迁移。
3. 恢复：磁盘、卷、NVRAM、TPM、恢复点、克隆和备份。
4. 工作台与观测：画布、对象操作、连接、流式文件、资源曲线、通信与抓包。
5. 真实验收：固定版本、Windows/AD、混合资产、操作中断、并发、故障处理与清理。

本轮发现与处理：

| 分类 | 证据与处理 |
| --- | --- |
| 产品错误 | 网络更新强制停机导致来宾 SSH 密钥文件未完整落盘。变更与回退改用已有正常停止阶段；暂停 VM 先恢复再正常关机。真实网络更新与原文件保留已通过。 |
| 产物错误 | 运行节点仍是旧构建，机器别名为空，无法匹配 `pc`。换用 `cf8ee3b` 集成节点；实际接口返回 `pc/q35` 与 canonical machine，模板导入通过。未增加匹配兜底。 |
| 测试时序 | 扩盘重启后约 3 秒即请求重建关机；来宾约 10 秒才启动电源事件服务，关机超时并真实回退。脚本增加真实 SSH 来宾断言；产品未增加健康门槛、自动强停或延长超时。 |
| 环境故障 | 最新一轮两个混合环境 SSH 已通过，后续专项 SSH 超时；同时 PostgreSQL 终止连接、控制面退出、WSL 无法启动 root 进程。C 盘仅剩 308.6 MiB，Ubuntu 虚拟磁盘由 11.85 GiB 增长至 25.23 GiB。测试暂停，现场保留，整轮记录失败。 |
