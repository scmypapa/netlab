# 实施记录

基准：`design/design.md`、`design/product-comparison.md`。平台代码参考为 `bff10f0`，新产品独立开发。

## 施工顺序

1. 基础执行闭环：契约、PostgreSQL 任务、容量预留、模板、虚拟硬件、启动前容器网络、混合环境创建与销毁。
2. 网络与运行变更：跨节点、重叠网段、多网卡、差异预览与应用、服务入口、VPN、迁移。
3. 恢复：磁盘、卷、NVRAM、TPM、恢复点、克隆和备份。
4. 工作台与观测：画布、对象操作、连接、流式文件、资源曲线、通信与抓包。
5. 真实验收：固定版本、Windows/AD、混合资产、操作中断、并发、故障处理与清理。

### 当前收尾
