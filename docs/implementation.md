## 施工顺序

2. 网络与运行变更：跨节点、重叠网段、多网卡、差异预览与应用、服务入口、VPN、迁移。

4. 工作台与观测：画布、对象操作、连接、流式文件、资源曲线、通信与抓包。
5. 真实验收：固定版本、Windows/AD、混合资产、操作中断、并发、故障处理与清理。

### VPN：连续真实验收

2026-10-03：控制面执行 `cfa2526`，节点执行 `6430170` 对应的地址回放与启动恢复实现。两个控制面共享现有 PostgreSQL；两个 Worker 继续复用 containerd、libvirt 和 OVN/OVS。未重建基础设施。

VPN 使用同一 Operation、节点计划及端口注册表。客户端私钥由浏览器生成，只保存在页面内存；服务器保存公钥。环境网关由原生 WireGuard、独立网络命名空间和 OVN 实现。原地址模式用于直接接入；转换模式分配独立访问前缀，支持同时访问重叠网段，来宾地址保持不变。

执行与数据提交已闭环：节点成功后才登记授权；父环境变更将 VPN 结果和场景修订放在同一数据库事务。失败沿现有任务恢复阶段重放原网络与客户端地址，释放未生效的端口和前缀。节点启动使用同一执行器重放持久配置。
